HTML + JavaScript + Fetch API

서비스 이용 대시보드

API Gateway를 통해 회원, 서비스, 신청, 추천 마이크로서비스를 한 화면에서 호출합니다.

인증 토큰

Swagger 또는 OAuth2 로그인으로 받은 JWT를 저장합니다.

Bearer
저장된 토큰이 없습니다.
현재 소스에는 POST /users/login이 없고 OAuth2 Authorization Code 방식을 사용합니다. 따라서 비밀번호를 직접 전송하지 않고 발급받은 토큰만 저장합니다.

회원가입

새 서비스 이용자 또는 서비스 제공자를 등록합니다.

POST /users/register

회원 정보 조회

회원 ID로 이름, 이메일, 역할을 확인합니다.

GET /users/{id}

서비스 목록

전체 또는 카테고리별 서비스를 조회하고 상세 정보를 확인합니다.

GET /courses

서비스 상세 조회

목록의 상세 보기 또는 서비스 ID를 사용합니다.

GET /courses/{id}

서비스 등록

서비스 제공자 토큰으로 새 서비스를 등록합니다.

POST /courses

서비스 신청

로그인한 이용자가 선택한 서비스를 신청합니다.

POST /enrollments

이용 서비스 목록

회원별 서비스 신청 내역과 상태를 확인합니다.

GET /enrollments/user/{userId}

추천 서비스

서비스 이용 이력을 기준으로 추천 결과를 조회합니다.

GET /recommend/{userId}
PATCH /enrollments/{id}/status는 현재 EnrollmentController에 구현되어 있지 않습니다. 신청 상태는 결제 완료 Kafka 이벤트에 의해 변경됩니다.

최근 API 응답

요청 성공 여부와 JSON 응답을 확인할 수 있습니다.
